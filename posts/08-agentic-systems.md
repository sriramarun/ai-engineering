## What this week covers

Agents as a computing paradigm. Anatomy of the loop: planner, executor, tools, memory, verifier. Tool design for production. State, memory, and compaction. Long-running work, retries, partial failure, and loop budgets. Multi-agent orchestration — when a second agent earns its cost. When the Claude Agent SDK is the right harness and when a plain tool loop is enough.

## What you'll build

Scholar's retrieval becomes an agentic research workflow: the agent plans a multi-step search, calls tools, verifies its own citations, and returns a report with a citation graph.
