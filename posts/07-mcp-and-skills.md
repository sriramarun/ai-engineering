## What this week covers

What MCP is and why a protocol beat bespoke integrations. Tools, resources, and prompts. Designing a tool an agent can use well — naming, typed parameters, honest errors, and what belongs in a description. Transports (stdio and HTTP) and the authorization spec. Agent skills as reusable, packaged capability.

## What you'll build

An MCP server that exposes Scholar's eval harness and database schema to your agent, so it can run your evals and read your migrations without you pasting anything.
